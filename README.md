# Productivity Tracker Plugin
**Автор**: Антонов Даниил Игоревич, группа М3103  

## Описание
Плагин для IntelliJ IDEA, который отслеживает активность пользователя в редакторе кода и визуализирует статистику прямо в окне IDE.  

## Функции
- Подсчёт количества редактирований (событий изменения документа).
- Отслеживание времени, проведённого за набором текста.
- Отслеживание времени просмотра (сколько секунд прошло с момента переключения между редакторами).
- Гистограмма активности за последние минуты (скользящее окно из 60 минут).
- Отдельное окно (Tool Window) с панелью визуализации статистики.
- Надёжная интеграция с API платформы (DocumentListener, FileEditorManagerListener, ScheduledExecutorService).
- Возможность остановки / запуска трекера, безопасное завершение планировщика и отписка от событий.
- Снэпшоты статистики (редактирования, секунды набора текста, секунды просмотра, список последних минут набора текста) для дальнейшей обработки или отображения.

## Как установить
1. Склонируйте репозиторий.
2. Постройте плагин с помощью Gradle (или другого билд‑инструмента).
3. Установите в IDE: *File → Settings → Plugins → Install plugin from disk* и выберите полученный ZIP/JAR.
4. Перезапустите IDE, затем откройте окно Tool Window → Productivity Tracker, чтобы видеть статистику в реальном времени.

## Использование
- При запуске проекта автоматически стартует отслеживание активности: создание слушателей, запуск планировщика.
- После переключения между файлами или редактирования кода статистика обновляется.
- В панели отображаются: количество правок (Edits), количество секунд набора текста (Typing (s)), количество секунд просмотра (Viewed (s)), а также гистограмма активности по минутам за последний час.
- Чтобы остановить трекер (например, при закрытии проекта или отключении плагина) - используется метод `stop()`.

## Архитектура
- Класс `ActivityTracker` - основная логика: подписка на события, подсчёт, буфер последних минут набора текста.
- Класс `TrackerPanel` - визуализация статистики через Swing / JBPanel, таймер обновления каждую секунду.
- Класс `TrackerToolWindowFactory` - точка входа плагина: создаёт трекер и панель, добавляет в Tool Window.
- Используется `ScheduledExecutorService` для периодической фиксации количества секунд набора текста и сброса минутных «корзин».
- Thread‑safe счётчики (Volatile, синхронизация) для корректной работы в многопоточном окружении.
